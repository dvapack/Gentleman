Основная идея проекта - телеграм бот, который должен поддерживать загрузку рилсов и тиктоков при обнаружении ссылки на
таковые в чате. Также дополнительно бот должен кешировать уже загруженные ссылки, реализовывать политику rate limit и 
параллельных запросов.

Открытые вопросы:
1. Какую библиотеку юзаем для взаимодействия с тг
2. Как реализуем rate limit
3. Как реализуем параллельные запросы

Основной флоу:
1. Пользователь присылает сообщение
2. Бот получает сообщение
3. Бот парсит ссылку и определяет сервис, из которого нужно скачивать
4. Видеоролик скачивается и отправляется пользователю
5. Ссылка сохраняется в Redis
